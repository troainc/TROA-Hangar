# Hangar+ Guides

Use these guides with the public [sample configuration](../TROA-Hangar.cfg.example). Install the plugin package from the [Releases page](https://github.com/troainc/TROA-Hangar/releases). Hangar+ runs on Torch; players do not install a client mod.

- [Player guide](PLAYER-GUIDE.md): store, retrieve, list, buy, sell, bid, and claim ships.
- [Server owner setup](SERVER-OWNER-SETUP.md): install, verify, configure optional integrations, and maintain storage.
- [Configuration reference](CONFIGURATION.md): what the main settings do and which integrations are optional.
- [Command reference](COMMANDS.md): player and administrator command syntax, plus Discord command restrictions.
- [Troubleshooting](TROUBLESHOOTING.md): common storage, market, Discord, and deployment problems.

Hangar+ owns Hangar storage, market listings, auctions, claims, commodity exchange, and its market webhook. Monitor+ can relay eligible chat commands from Discord; Econ+ can optionally handle durable credit escrow. Neither is required for basic Hangar storage or market operation.
