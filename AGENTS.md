# Repository guidance

- Keep this repository within the public documentation/release scope for TROA Hangar+.
- Document only behavior verified by the currently published release; label candidate, planned, estimated, or unverified behavior clearly.
- Keep source, private configuration, credentials, test data, and unreleased binaries out of public documentation.
- Keep README, changelog, configuration examples, command references, and detailed guides consistent with one another.
- Validate all Markdown links and command examples against the matching version before publishing.
